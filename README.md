# 🍅 Nitya's Portfolio — *Every model starts messy*

A single-page, story-driven portfolio built like a hero's journey — hand-drawn, interactive, and definitely not a template.

**[https://nitya-zijoo.github.io/Portfolio/](#)** 

## What's inside

- Hand-sketched buttons and scribbles ([rough.js](https://roughjs.com/))
- A cursor-tracking mascot (bottom-right — say hi 👋)
- Wobbly scroll-progress path instead of a straight line
- Confetti burst on the "Email me" button
- Six chapters: Origin → Tools → Trials (projects) → Allies (papers) → Return (contact)

## Stack

Just `index.html` — vanilla HTML/CSS/JS + rough.js via CDN. No build step, no dependencies to install.

## Run locally

Open `index.html` in a browser. That's it.

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch `main`, folder `/root`

## Edit before publishing

Search for `edit-me` / `EDIT ME` in `index.html`:
- Real email + LinkedIn URL (footer)
- A few generic GitHub links point to the profile root — swap in exact repo URLs
- The "why AI/ML" line in the Origin chapter
